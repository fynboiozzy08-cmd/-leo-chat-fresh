LEO CHAT — FRESH WEB VERSION

1. Upload all files in this folder to a NEW web repository.
2. Open config.js.
3. Keep the Supabase URL already there.
4. Replace PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE with your existing Supabase PUBLISHABLE key.
5. Never put the sb_secret/service_role key in this project.
6. Deploy the repository with GitHub Pages or another HTTPS host.
7. Open the HTTPS site in Safari on iPhone.
8. Use Safari Share -> Add to Home Screen.

This build uses the existing public.profiles and public.messages tables.
Media selection is local and currently sends a message label; cloud media storage is a later module.
Voice/video buttons are placeholders for the calling module.
